# Code of Conduct

## Our Pledge

We are committed to making participation in this project a harassment-free experience for everyone.

## Our Standards

- Be respectful and constructive
- Accept feedback gracefully
- Focus on what's best for the project and the students using it

## Enforcement

Unacceptable behavior can be reported by opening an issue. Maintainers reserve the right to remove contributions that violate this standard.

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.
