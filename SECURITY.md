# Security Policy

## Supported Versions

This project is in early development. Only the latest commit on `main` is actively maintained.

## Reporting a Vulnerability

Please do **not** open a public issue for security vulnerabilities.

Instead, email directly or open a [GitHub Security Advisory](https://github.com/G10rga/Litera/security/advisories/new) on this repo.

I'll respond within a few days and coordinate a fix before any public disclosure.
