# Contributing to Litera

Thanks for your interest! This project is in early development.

## How to Contribute

1. Fork the repo and create a branch: `git checkout -b feature/your-feature`
2. Make your changes
3. Test locally (`flask run`)
4. Open a Pull Request with a clear description of what you changed and why

## What's Useful Right Now

- Adding or correcting literary content (summaries, character analyses)
- Bug fixes in `app.py` or `models.py`
- Frontend suggestions or mockups

## Code Style

- Python: follow PEP 8
- Commit messages: short and descriptive in English

## Questions

Open an issue and tag it `question`.
